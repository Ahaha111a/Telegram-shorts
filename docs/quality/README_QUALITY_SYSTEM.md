# Telegram Shorts — комплект системы качества

Комплект добавляет постоянные правила, стартовый реестр требований и известных дефектов, QA-чек-лист и дизайн-правила. Он не меняет приложение, бота, базу данных или текущий UI.

## Состав
- `PROJECT_RULES.md` — рабочие правила.
- `REQUIREMENTS.md` — реестр требований.
- `BUG_LEDGER.md` — известные дефекты.
- `QA_CHECKLIST.md` — проверки перед выпуском.
- `DESIGN_SYSTEM.md` — дизайн и UX.

## Ограничения
1. Этот комплект не устанавливает автоматические тесты и не подключает GitHub Actions.
2. Статический анализ не доказывает, что интерфейс работает в Telegram WebView.
3. Реальное поведение Telegram/Railway/Supabase требует runtime-проверки.
4. Записи в `BUG_LEDGER.md` — известные симптомы; статус причины указывается отдельно.
5. Эти документы ещё нужно добавить в GitHub. Сам факт подготовки архива не означает, что репозиторий изменён.

## Размещение в репозитории
Все пять основных Markdown-файлов и этот README разместить в корне репозитория. Не заменять ими файлы приложения.
