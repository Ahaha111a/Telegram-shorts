# Telegram Shorts — система дизайна и UX

## Направление
Тёмный, строгий, современный и премиальный интерфейс с собственной идентичностью. TikTok/Reels — ориентиры поведения, а не источник для копирования бренда.

## Обязательные правила
1. Видео — главный слой экрана; элементы управления не перекрывают важный контент без необходимости.
2. **Нижней навигационной панели нет.** Поиск, создание, уведомления и профиль доступны через компактные кнопки верхней панели. Не резервировать место внизу.
3. Истории просмотров и встроенной камеры нет.
4. Учитывать safe-area, Android WebView, динамическую высоту экрана, клавиатуру и Telegram BackButton.
5. Текст не выходит за границы; длинные username/описания переносятся или обрезаются по явному правилу.
6. Иконки центрированы, области касания удобны, подписи не смещают их.
7. Загрузка, пустой список, ошибка, повтор и отключённая кнопка имеют явные состояния.
8. Касание лайка/комментария/поделиться не должно вызывать паузу видео.
9. Анимации не задерживают действие и не показывают ложное пустое состояние.
10. Общие CSS-изменения проверять на всех затронутых экранах.

## Проверка дизайна
Статическое чтение CSS не считается визуальной приёмкой. Скриншоты/реальный Telegram WebView нужны для подтверждения размеров, перекрытий и touch-поведения.
