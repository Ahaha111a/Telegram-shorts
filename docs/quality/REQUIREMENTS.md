# Telegram Shorts — реестр требований

Статусы: `CONFIRMED` — подтверждено пользователем; `BASELINE` — зафиксировано из предыдущего контекста, актуальную реализацию нужно проверить; `DONE` — подтверждено тестом; `BLOCKED` — проверить не удалось.

Приоритеты: `P0` — блокирует использование/безопасность; `P1` — критическая функция; `P2` — качество и удобство.

## Правила обновления

1. Не менять статус на `DONE` без доказательства.
2. Новые требования получают новый ID; ID не переиспользуются.
3. Отменённое требование помечать `CANCELLED` и указывать замену.
4. Для каждого требования нужен тест или явное объяснение, почему требуется ручная проверка.
5. `BASELINE` означает, что требование известно, но актуальная реализация ещё не подтверждена.
