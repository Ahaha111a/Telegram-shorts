# Telegram Shorts — реестр требований

## Правила
- Не ставить `DONE` только по наличию кода.
- Сохранять ID требований; отменённые помечать `CANCELLED`.
- Для каждого изменения добавлять проверку против регрессии.


## Обновление v13
- Удалено затемнение нижней части видео из `.video-gradient`; оставлено только мягкое затемнение сверху.
- Двойной тап в ленте и просмотрщике сохранённых использует общий обработчик лайка, поддерживает включение/снятие лайка и сериализует быстрые переключения.
- Для неактивных роликов выставлен `preload="none"`; активный ролик получает `preload="auto"` при попадании в viewport.
- Профиль: выравнивание статистики через фиксированные line-height/tabular numerals и лёгкие переходы.
- Реальная визуальная и Telegram WebView-приёмка по-прежнему не выполнялась.
