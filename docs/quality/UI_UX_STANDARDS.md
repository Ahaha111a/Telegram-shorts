# UI/UX standards

- Mobile-first; учитывать `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`. Не полагаться на `100vh`; использовать `100dvh` с проверкой fallback.
- Для вертикальных коллекций применять scroll snap с высотой карточки, равной реальной видимой области scroll container, а не автоматически `window.innerHeight`.
- Не размещать градиенты с непрозрачным чёрным цветом на нижних 40–50% видео без продуктового решения. Тени текста применять к тексту, не ко всему видео.
- Проверять все повторные CSS overrides и псевдоэлементы. Один локальный CSS fix не считается достаточным, если другие правила могут перекрыть его.
- Навигационная панель может иметь собственный фон, но не должна создавать внешнюю тень/градиент, затемняющий заметную часть видео.
- Кнопки действий не должны всплывать в обработчик видео и переключать паузу.
- Профильные сетки должны использовать `poster` для thumbnail и `preload="none"` для видео вне просмотра.
- Системные элементы Telegram/Android не скрывать принудительно.
- Анимации учитывать `prefers-reduced-motion`; избегать больших blur/shadow на движущихся слоях.
