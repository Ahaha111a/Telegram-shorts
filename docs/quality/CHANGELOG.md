# Changelog

## 2026-10-17 — boot recovery and threaded comments

- Ограничены по времени запросы авторизации и получения профиля при запуске.
- Добавлен fail-safe заставки и возможность повторного запуска.
- Добавлены ответы на комментарии через `comments.parent_id`.
- Добавлена безопасная миграция схемы, проверка родительского комментария и подсчёт комментариев по данным БД.
- Обновлён интерфейс обсуждений: ветки ответов, состояние ответа, отправка с защитой от повторного запроса, ошибки и пустое состояние.
- Добавлены статические регрессионные тесты.
