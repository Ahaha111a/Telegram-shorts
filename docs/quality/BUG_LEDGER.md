# Telegram Shorts — автономный реестр дефектов

Этот файл ведёт разработчик. Пользователь не обязан добавлять записи вручную.

## Правила

- Использовать стабильные ID `BUG-###`.
- Не выдавать гипотезу за установленную первопричину.
- После исправления добавить регрессионный тест и сохранить запись в истории.
- При повторном обнаружении переоткрыть существующий ID, а не создавать дубликат.
- Без достаточных данных ставить статус `NEEDS-REPRODUCTION`.

## Подтверждённые наблюдения из текущего чтения GitHub

- `dist/index.html` содержит нижнюю панель с пунктами «Главная», «Поиск», «Создать», «События», «Профиль».
- В CSS определено несколько правил `.bottom`, включая позднее правило, которое убирает затемнение, но не удаляет саму панель.
- `README.md` говорит, что нижняя панель скрывается при открытых панелях; это не равнозначно полному удалению.
- `README.md` заявляет, что интерфейс и хранение истории просмотров не используются. Это заявление ещё нужно сопоставить с полным кодом и реальным интерфейсом.
- README сообщает о проверках версии v11, но они не заменяют проверку текущего пользовательского сценария на устройстве.
