# Product specification

## Ядро
1. Telegram Mini App авторизует пользователя через проверенные Telegram WebApp initData.
2. Лента показывает вертикальные видео; активное видео воспроизводится, неактивные приостанавливаются.
3. «Для тебя» и «Подписки» имеют отдельную загрузку, корректные loading/empty/error состояния.
4. Лайк, сохранение, комментарий, подписка, жалоба и удаление собственного видео должны изменять серверные данные.
5. Профиль показывает пользователя, статистику и публикации с обложками, если они доступны.
6. Поиск, уведомления, сохранённые публикации и создание видео должны сохранять состояние и поддерживать возврат назад.
7. Ссылки на публикацию должны открывать Telegram Mini App через `startapp`, если Main Mini App настроен в BotFather.

## Явные продуктовые решения
- Не показывать интерфейс истории просмотров. Не удалять схему/данные истории автоматически.
- Не добавлять камеру.
- Нижняя навигация остаётся на главном экране, не должна создавать широкое затемнение видео над собой.
- Свайп между роликами должен работать одинаково в ленте, профиле, поиске и сохранённых видео.

## Приёмка
- Состояние лайка и счётчик синхронны с API после успеха; при ошибке показывается сообщение и UI не притворяется сохранённым.
- Двойной тап не переключает воспроизведение и вызывает одно действие лайка.
- Одна вертикальная прокрутка переводит на соседний ролик без пропуска/двойного шага.
- Нет пустого состояния до завершения загрузки.
- Неподтверждённые внешние интеграции маркируются как требующие проверки.
